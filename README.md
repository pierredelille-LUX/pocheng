# 战西夏 1.4

[在线游玩](https://pierredelille-lux.github.io/pocheng/)

七关战役：守城、野战、峡谷、渡河、护粮道、夜袭、破城。支持简单、中等、困难三档难度和自动、手动存档。

手机使用屏幕摇杆及动作按钮。电脑使用 WASD 移动，J/空格射击，K/Shift 翻滚，L/E 投掷，H/Q 用药，B 行囊，P 存档。

本仓库只包含发布文件。开发源码、测试和构建历史保存在私有仓库。

存档保存在当前浏览器；1.3/1.4 存档兼容，旧版六关存档无法继承。见 [隐私说明](PRIVACY.md) 和 [第三方许可](THIRD_PARTY_NOTICES.txt)。
